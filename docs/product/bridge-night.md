# 溪桥之夜 · 第一章可玩样片

**本轮体验目标**：让玩家记得是谁把灯留在了窗边，理解溪桥上为何值得少打一张攻击牌，并在营火收到对自己选择的回应。先交付这段约 8–12 分钟的完整体验，保留独立闪卡、已有存档和文字 CLI。以下是新版本的创作提案；范围与节奏由首轮试玩校准。

## 从当前第一章起步

`content/warm-lantern/editable/story.json` 第一章已有 9 个节点，`inn.arrival` 和 `forest.signpost` 两个选择节点各有一个选项。`camp.letter` 固定称玩家写对了两个词，题目和作答并不总是如此。`AdventureJourney.vue` 以一段 `node.text` 加操作按钮呈现对白。`BridgeBattlePanel.vue` 已提供手牌、敌方意图、快捷键与声音，`PhaserAudioGame.ts` 的 120×44 宿主用于声音与符文反馈。复用这些领域命令、场景背景、六表情立绘与现有音效，将此次工作集中在可见舞台、角色对戏和选择后果。

## 第一幕的戏怎么演

莉娅知道祖母会在雾夜朝桥上挂一盏灯，想把最后一盏好灯留给晚归的人。瑟琳检查过桥栏断口，坚持今晚过桥的人也需要灯。两人都在照顾别人，意见却相反。玩家决定由谁承担代价，伙伴在行动中给出回应。

| 地点 | 玩家读到、听到与看到的事 | 可操作的选择与回报 |
| --- | --- | --- |
| 旅店，打烊后 | 窗外先响三下铜铃。莉娅手里的火柴已经划亮，停在灯芯前。瑟琳摊开地图，指腹沾了一条新泥痕。 | 先点泥痕或灯钩看不同细节；可直接进入两人的争执。独自点屏推进的动作始终写“继续”。 |
| 窗边，双人同框 | 莉娅：“去年我走丢的时候，从桥上只看得见这一扇窗。”瑟琳：“我下午摸过桥栏。第三截绳子，拉一下就断。”她把手心摊开，一根麻丝嵌在指节上。 | **把灯留在窗边**：莉娅把窗闩抵紧，瑟琳取下地图的红系绳。**请莉娅提灯同行**：莉娅递来灯，转身用粉笔在窗板上画一支回家的箭。选择结果落入本 run 并立即可见。 |
| 溪桥，抵达 | 留灯路线在身后看见一个稳定的暖点，脚下的路要摸索；携灯路线能看到桥栏的影子，回头只有黑窗。 | 先读敌方意图，再决定打牌。路线修正首次遭遇的公开条件，进战前显示给玩家；下文给出初始数值。 |
| 营火，双路线合流 | 留灯路线：对岸有一点灯火晃了三下，莉娅终于松开一直抓着的窗钥匙。携灯路线：归途中粉笔箭头旁多了一行小字，“看见了，明早替你擦”。瑟琳主动把这句话抄到地图背面。 | 胜利与救援分别有一句具体的行动回忆，均能看到选路回收。玩家可以回看原话；若没有真实作答证据，对白只陈述场景事实。 |

正式剧本按可编辑的逐句脚本交付，每拍一个主要动作或说话意图。每条记录有稳定的行 ID、实际说话人、文本、左右站位/表情、可选音效或镜头提示。独白与旁白明确标记，叙事中的称呼遵循实际说话者和听者。每条路线安排一句只有这两位伙伴能说出来的话。首轮直接沿用手绘背景和立绘，新增物件用灯钩、红系绳和窗板三个清楚的视觉标记即可。

## 怎样让英语进入这场戏

灯下有张残缺的路条，写着 `Keep the ___ lit until dawn.`。玩家用“提灯”的英语补全文字。提交后莉娅在路条背面画下小小的灯，不读系统评分；战斗时在上下文不同的一次引导练习中认出 `lit` 指灯还亮着。后者属于语境理解，保持现有正式学习目标定义。首次回忆若该词已在剧情里以英文展示过，转为引导练习。空队列或当天上限已到时可读信、求助或扎营，同样能看到剧情出口。Again 与 Easy 获得同样的回合基础能量。

## 一场会想换打法的卡牌战

用现有“突刺、守护、余烬”和伙伴协助验证两种战术。为本章的新遭遇版本设置以下教学初值，不调整所有书的全局数值。

- 留灯走暗桥，瑟琳的系绳在首回合提供 5 点格挡；携灯看清守卫铆钉，首回合第一次直接攻击多造成 3 点伤害。两项只在开局应用一次；界面和 CLI 在选择前都描述作用。剧情选择影响处境，后续照样可以自由攻守。
- 守卫先举臂准备攻击，玩家打守护能看见其代价与收益；守卫准备加盾时，玩家可尽量输出，或用余烬安排后续持续伤害。教学牌序固定。两条路线各做一次同牌序对照试玩，记录挡下多少、造成多少、下回合遇到什么，按结果调数值。若连续打攻击是所有局面的最优解，继续调这个遭遇。
- 一次有效出牌展示四步：牌从手中抬起并指向目标，角色挥动或施法，命中点出现，生命或护盾变化。格挡采用木击声和逐层碎开的盾纹，灼烧在敌方行动前由残火跳动一次。一个动作只突出一个结果，牌回落或飞入弃牌堆后焦点回到下一张可用牌。
- 准备动作可即时播放，伤害、死亡、奖励与剧情标志由现有权威状态确认后演出。失败、重试、重载只显示正确结果；重放动画和回看对白没有业务副作用。救援保留正式学习记录，并给一段同样值得看的角色反应。

## 舞台与输入

把本章的公共场景区域用于完整的可见演出，采用现有 Phaser 4 和 Vue 的组合。角色、手牌和目标的起终点共用布局坐标。Phaser 做镜头、卡牌飞行和命中特效；Vue/DOM 保持文本、输入、自评、按钮和焦点语义。复用现有声音与生命周期，避免同时创建两个抢键盘、播相同音效的 Game 实例。

对话有独立的底部文本框、姓名牌和历史记录，双立绘同框，发言者靠近镜头，听者保留反应。无语音时用停顿、纸响和灯芯熄灭来分句。点击或 Enter 第一次补全本句，第二次进下一句；自动播放在选择处停下，跳读默认只过已读，历史只读。图像淡入约 180–300 ms、命中短停约 60–90 ms 作为调校起点；停止的是画面，输入法与领域时钟照常工作。允许调字速、减少动态、跳过演出和静音。网络返回或后台恢复在当前行/检查点重建画面，不能吞掉一个选择、重复评分或要求玩家重读整章。

在新版本 `.fmbook` 中声明演出能力；使用声明式指令处理站位、表情、音效和镜头。旧版 `text` 可映射为一拍对白。给分歧使用稳定 choice ID，章末回收依据已提交的分支事实；账号端、CLI 和本地模式沿用同一事实。CLI 直接输出说话人、台词、选项和公开修正。新包另发版本，已有 run 按原内容锁定/显式升级约定恢复。

## 制作顺序和试玩判断

| 切片 | 实际玩到的交付 | 放行条件 |
| --- | --- | --- |
| 1. 旅店读剧 | 用新脚本和现有两张立绘完成窗边争执，两个选择分别接一段营火回收；先可用静态分镜 | 玩家能说出两个人各自害怕失去什么，愿意重玩看另一条；第二遍能跳已读对白。 |
| 2. 舞台演出 | 实装双人站位、道具声、镜头和灯的来去，连上现有冒险入口 | 静音仍看得懂谁在说话；恢复能接上原句或相邻明确检查点，减少动态可完成同一路线。 |
| 3. 溪桥战 | 公开开局差异、敌方意图、出牌到命中反馈，用真实英语任务与真实学习回执通关 | 玩家能指出一次因敌方意图而改变的出牌；遮住数字也分得出“打中”和“被挡”。 |
| 4. 合成首章 | 正常入口走完两种选择、一次救援、刷新恢复和营火回收；用同一格式给下一章做一个新场景 | 从新存档实际玩一遍，用不同选择再玩。让玩家指出最想多看一句的角色、最想跳过的一拍和一个想尝试的打法。根据具体回答修改，再扩到全书。 |

录制两条带声音的短试玩（一次主要分支和一次不同选牌回合），放在 `.local/evidence/`。本轮用户试玩与具体反馈决定是否扩写其他章节；实现验证按项目规定逐个切片本地提交。
